# Balance Analysis Skill

Use this skill to analyze and adjust numerical balance without changing core system rules.

## Inputs

- Scope (cards, enemies, encounter, or subsystem).
- Current values and target outcomes.
- Constraints that must remain fixed.

## Workflow

1. Capture baseline values and observed pain points.
2. Identify high-impact numeric levers.
3. Propose bounded adjustments with rationale.
4. Define scenario-based validation cases.
5. Summarize rollback-safe tuning steps.
